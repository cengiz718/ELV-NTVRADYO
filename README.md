# ELVİN TV RADYO

Android IPTV player for user-provided, authorized playlists. Independent project; does not include copyrighted channel streams or third-party app code/assets.

## Features
- M3U/M3U8 playlist URL and local M3U import
- TV and radio sections, categories, search and favorites
- ExoPlayer playback, landscape/fullscreen controls
- Android phone, Android TV and TV Box focus/remote navigation foundations
- GitHub Actions APK build

## Build
Push to `main` or run **Build Android APK** from Actions. Download the APK from the workflow run's Artifacts.

## Requirements
Android 7.0+ (API 24). Use only playlists and streams you are authorized to access.
